# SQL Practice

Практика SQL на учебной базе интернет-магазина: покупатели и заказы.
СУБД: SQLite (запросы совместимы с PostgreSQL в рамках базового синтаксиса).

## Что внутри

- `queries.sql`: схема, тестовые данные и все запросы с комментариями
- `sql_practice.ipynb`: те же запросы в Jupyter с результатами (через Python и pandas)

## Темы

- Выборка и фильтрация: SELECT, WHERE, ORDER BY, LIMIT
- Агрегации: COUNT, SUM, AVG, GROUP BY, HAVING
- Объединение таблиц: JOIN, LEFT JOIN
- Подзапросы и CTE (WITH)
- Оконные функции: SUM() OVER, ROW_NUMBER() OVER (PARTITION BY)

## Примеры задач

- Топ-N самых дорогих заказов
- Покупатели без заказов (LEFT JOIN, NOT IN)
- Покупатели с суммой выше средней (CTE)
- Накопительная выручка по датам
- Самый дорогой заказ каждого покупателя
